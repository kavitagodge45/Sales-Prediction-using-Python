# Sales Prediction using Python

# Objective
This project predicts future sales based on advertising expenditures using Machine Learning.

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

# Dataset
Advertising dataset containing:
- TV Advertising Budget
- Radio Advertising Budget
- Newspaper Advertising Budget
- Sales

# Steps Performed
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Correlation Analysis
5. Train-Test Split
6. Linear Regression Model
7. Sales Prediction
8. Model Evaluation

# Evaluation Metrics
- MAE
- MSE
- RMSE
- R2 Score

# Conclusion
The model successfully predicts sales based on advertising spending and shows how advertising platforms impact sales outcomes.
